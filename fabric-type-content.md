# Weaving Vibes — Fabric Type Content Library

How to use this: each fabric type below has the same content slots as your `Cheesecake` page (Nav Tag, About, Quote, Tags, Lifestyle bullets, Stats, Ticker). When you build a new fabric's HTML page, find its **Type** here and copy-paste the matching blocks straight into the template, then swap in that specific fabric's own Name / GSM / Width / Colours / Hero image (those stay fabric-specific, not type-specific).

All facts below are sourced from textile industry data and fiber sustainability research (LCA studies, Lenzing/TENCEL technical data, hemp-cotton comparative studies). Stats are presented as typical/industry-reported ranges — swap specific numbers if your supplier/lab data differs.

## Notes on use

- **Fabric-specific fields** (NOT in this doc — fill per swatch): Fabric Name, GSM, Width, Weave Type, Hero image, Available Colours, sample request form fabric name.
- All "Exported to 20+ countries," "Made in India," "Low MOQ," "Customisable," and "Global Exports" lines are Weaving Vibes brand-level claims (not fiber-specific) — keep these consistent across all types unless you want to verify/update the exact export country count.
- Numbers in stats are presented as typical industry-reported ranges based on current textile sustainability research; if your factory/lab has its own tested GSM-specific or supplier-specific figures (e.g., your own water usage data), swap them in — real internal data will always be stronger than generic industry stats.
